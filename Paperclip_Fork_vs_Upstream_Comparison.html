1. Executive Summary & Strategic Positioning

The repositories diverged on April 27, 2026 at commit d0bdbe11a. Since then, the fork and upstream have developed under two distinct product visions:

The User Fork: "The Executive Desktop Cockpit"

Primary Goal: Personal operating cockpit for an executive/founder managing multiple ventures from a local Windows workstation.

  • Native Desktop Runtime: Custom Rust system tray app, desktop toast notifications, and process-tree guards.
  • HQ Portfolio Operations: Cross-company directives, unified executive brief, aggregate receipts, and private personal spaces.
  • Unified Communications: 3-pane email client (IMAP + Help Scout), auto-triage, AI drafting, and task creation.
  • Clippy Assistant & Trust Loop: In-app drawer with interactive permission cards & outbound mutating tool gates.
  • Cost Optimization: Switchboard multi-account rotation and local models (Ollama, Aider).

Official Upstream: "The Enterprise Agent Cloud"

Primary Goal: Scalable, multi-tenant enterprise agent execution platform for distributed teams and cloud infrastructure.

  • Decoupled Runner Daemon: Standalone paperclip-runner for remote worker nodes and Docker/Daytona sandboxes.
  • Enterprise Governance: MCP Tool Gateway proxy, fine-grained OAuth grants, and low-trust agent isolation.
  • Pipelines & Cases: Multi-stage DAG blocker state machines and collaborative incident desk.
  • Skill Studio: In-browser IDE for authoring skills with evaluation kernels and automated testing.
  • Multi-User IAM: Responsible-user commit attribution, user-specific secrets, and 30+ language translations.

Because migration sequence numbers were assigned independently on both branches:

5. "Which One Is Better?" Decision Matrix

Solo Founder / Executive Operator Your Fork Your fork provides a complete operational desktop environment (HQ portfolio overview, integrated email/Help Scout client, Clippy trust gate, desktop toast reminders). Upstream lacks desktop and communications infrastructure.
Windows Workstation Daily Driver Your Fork Upstream has no desktop executable. Your Rust system tray app, process tree cleanup, and restart/update scripts make running on Windows seamless and crash-resilient.

Multi-Human Team / Organization Upstream Upstream offers enterprise RBAC, "Responsible User" commit attribution, per-user private secrets, and decision desk tracking.
High-Scale Concurrent Agent Fleet Upstream Upstream's separated runner daemon, Daytona sandbox leases, and Git worktrees allow 10+ agents to develop code concurrently without workspace collisions.
Strict Security & Compliance Audit Upstream Upstream provides formal MCP Tool Gateways, low-trust agent isolation, OAuth revocation, and evaluation verification suites.

6. Strategic Recommendations & Action Plan

Recommended Strategy: Treat your fork as a specialized executive distribution. Do not attempt a full git merge.
  1. Keep Your Fork as Primary: Continue running your fork for your day-to-day operations. Its native desktop integration, email triage, and Clippy assistant cannot be replaced by upstream today.
  2. Cherry-Pick High-Value Upstream Adapters: If you want new agent harnesses (such as grok-local, kimi-local, or cursor-cloud), cleanly cherry-pick or copy the adapter packages from packages/adapters into your fork without touching the server core.
  3. Package Key Superpowers as Plugins: Upstream's official plugin system is now mature. Consider extracting Switchboard and Calendar into standalone Paperclip plugins that can run on any version.
  4. Monitor Upstream Runner Maturity: If you scale to remote cloud servers or require Daytona sandbox pools, consider deploying an upstream instance as a headless runner worker while keeping your executive cockpit intact.
