# v2026.922.1

> Released: 2026-09-22
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Restored Update Notification for Pushed Commits** — Fixes an issue where pushing new commits to GitHub from the local checkout caused the "Update" pill button in the bottom-left account menu to disappear. Paperclip now checks whether the installed build is behind the remote tip, ensuring you are always notified and given the option to pull and apply the latest updates.

## Fixes

- **Update Check Service (`check-for-updates`)** — Evaluates `installedCommit` against `remoteCommit` so that when commits have already been pushed to `origin/master`, Paperclip recognizes the running installation is behind GitHub and displays the update pill.
- **Git `ls-remote` Fallback** — Added a zero-rate-limit git fallback for remote head resolution if GitHub REST API calls hit unauthenticated rate limits (HTTP 403) or encounter transient connection errors.
- **Account Menu Tooltip Consistency** — Suppressed the "runs straight from the working tree" note whenever an update is available so the UI state remains clear and actionable.

## Upgrade Guide

- Existing Windows installations can use **Update Paperclip** directly from the UI pill or tray.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
