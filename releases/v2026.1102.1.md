# v2026.1102.1

> Released: 2026-11-02
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Docker image builds again.** The image's base moved to Node 26, which no longer includes corepack, so the v2026.1102.0 image failed to build and was not published. The base is now pinned to Node 24. This release carries everything in v2026.1102.0 (email snooze, the Snoozed view, and finished agent work handed back for review).

## Upgrade Guide

- Use **Update Paperclip** as before.
- If you run the Docker image, `ghcr.io/barrycarrjr/paperclip:latest` now points at this release.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
- No database migration is required.
