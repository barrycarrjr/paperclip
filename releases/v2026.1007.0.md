# v2026.1007.0

> Released: 2026-10-07
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Desktop reminders on macOS and Linux.** Reminders used to show only in the Windows tray. On a Mac they now appear as a dialog with Dismiss and Open, and on Linux as a desktop notification when `notify-send` is installed. A reminder you do not answer comes back later.

## Security

- **An Admin can no longer invite an Owner.** Inviting someone as an Owner or Admin now needs the same membership powers the invited role would get, so nobody can hand out more power than they have. Agent-only invitations are unchanged.
- **Agents can no longer change how they themselves run.** An agent can no longer edit its own adapter type, command, arguments, working folder, environment, secrets or permission-skipping setting.

## Fixes

- **"Ask permission" is no longer shown for Claude (local CLI) models in Clippy.** Those models cannot pause for approval, so the composer now shows them as Bypass permissions instead of promising an approval step that never happened.
- **The sign-in link printed at startup works.** In authenticated mode on a loopback address, the one-time board-claim link now uses `localhost`, so signing in from it no longer fails with "Invalid origin".
- **Stuck tasks no longer wake their agent over and over.** After two automatic retries, a stalled in-progress task is locked with a comment asking for a person to step in.
- **Plugin approval rules survive restarts.** Per-operation approval settings for plugins are kept after a server restart or plugin reload.
- **Email replies use the right reply tool** when a handoff was stored with the plugin's internal ID.
- **All built-in agent types are available.** Grok, Kimi, Cursor Cloud and Hermes gateway agents were missing from the list and are now registered.
- **Agents hired from library templates get the right adapter**, including templates that spelled it `claude-local`.

## Upgrade Guide

- Windows: use **Update Paperclip** from the UI pill or tray as before.
- macOS and Linux: use **Update Paperclip** as before. The reminder dialog starts with the server after the update.
- Server changes take effect once Paperclip restarts. The update restarts it for you.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
