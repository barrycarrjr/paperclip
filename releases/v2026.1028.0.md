# v2026.1028.0

> Released: 2026-10-28
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Task assignment to Builder via Clippy** — Board users interacting with Clippy can now create and assign tasks to the Builder agent in HQ (or agents across companies) via `create_issue` and `update_issue`.
- **HQ Authorization Gate** — Enforced strict permission checks ensuring only users who have active membership in HQ and the `tasks:assign` permission in HQ can relay task assignments to Builder. Unauthorized users or users with read-only/viewer access in HQ are strictly rejected.
- **Immediate Agent Wakeup** — Newly assigned tasks automatically trigger an agent wakeup so Builder can start working on the assignment immediately.

## Improvements

- Exposed `isPortfolioRoot` in `list_companies` and `get_company` chat tools so Clippy and users can reliably identify the HQ company.
- Enabled issue lookup by key/identifier (e.g. `HQ-42`) in chat tools in addition to UUIDs.
- Automatic routing: When assigning to Builder without explicitly specifying a company, `create_issue` automatically targets HQ.

## Upgrade Guide

- Use **Update Paperclip** as before.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
- No database migration is required.
