# v2026.1020.8

> Released: 2026-10-20
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Fixes

- Mail triage no longer asks permission just to record sender suggestions for review. The operator still decides what to do with those senders using the mail review controls. Explicit operation approval requirements still apply.

## Upgrade Guide

- Use **Update Paperclip** as before.
- Existing pending approval cards are retained. This fix prevents new review-queue prompts after updating, unless approval is explicitly required for the operation.
- No database migration or configuration change is required for this fix.
