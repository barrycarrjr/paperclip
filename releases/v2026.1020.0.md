# v2026.1020.0

> Released: 2026-10-20
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Features

- **Smart Multi-Company Calendar Routing & Auto-Tagging**: Supports dual-model Google Calendar usage across portfolios. A single Google account can be shared across subsidiaries with automated routing:
  - Events tagged with bracketed prefixes (e.g. `[BIN]`, `[IND]`, `[HQ]`, `[STR]`), hashtags (`#b2`, `#bin`), or colon prefixes (`BIN: Standup`) route automatically to their respective company calendars.
  - Untagged events automatically route to the Personal company calendar without leaking into subsidiaries.
  - Outgoing events created from Paperclip for a business subsidiary are automatically tagged with the company prefix.
  - Added in-flight request coalescing and 10-second TTL caching for Google Calendar event fetches, cutting duplicate API calls across multi-company portfolio views down to a single request.
  - Deduplicated occurrence displays across portfolio-wide calendar views.

## Fixes

- **Approvals**: Stop asking before an agent saves its triage bookmark.
- **Heartbeat**: Batch dependency wakeups by request.

## Upgrade Guide

- Use **Update Paperclip** as before.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
