# v2026.1008.1

> Released: 2026-10-08
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Features

- **Run permissions can be set once, for the whole instance or one company.** The "skip permissions" setting for Claude, Codex and OpenCode agents used to live on each agent separately. Instance Settings > Agent defaults now has a Run permissions section, and Company Settings can override it for one company (for example, a stricter company that handles email or money). An agent's own setting still wins. Each agent's setting has a new "Use default" choice, and the page shows the value that will actually apply and where it comes from. Only board users can change the company setting and only instance admins the instance one; every change is logged with before and after values. (#41, #42)

## Fixes

- **Agents can no longer turn on the Codex bypass flags for themselves.** Only the Claude skip-permissions flag was blocked from self-edit before.

## Upgrade Guide

- Use **Update Paperclip** as before. This release adds a database table, which is created automatically when the server starts.
- **Existing agents do not change.** They keep the value already stored on them until you choose "Use default" on each one. New agents follow the defaults. With no defaults set, behaviour is the same as before.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
