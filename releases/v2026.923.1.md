# v2026.923.1

> Released: 2026-09-23
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Replied and forwarded marks.** Email list rows and open messages now show whether a message has been replied to or forwarded, from any mail program, on the company Email page and on Portfolio Email, including search results and the pop-out. Forwarding from Paperclip marks the original as forwarded too, which is the icon Outlook shows.
- **Readable email lists.** List rows now give the sender and subject the full width. The quick actions float over the right end of a row only while you point at it, and beside an open message they are trimmed to Mark read or unread, Delete, and a More actions menu for the rest.
- **A wider list beside an open email.** Drag the edge between the list and the message to widen the list, and double-click the edge for the usual width. It never takes more than half of the space the mailbox column leaves, so the message always keeps the other half.

## Fixes

- **The list stays where you left it.** The Email page's list no longer jumps back to the top whenever the page updates, for example when you open a message further down or open a row's menu. It still starts at the top when you switch folder, mailbox, tab, grouping or search.
- **The message you are on stays in view.** Opening a message from the full-width list now shows that message in the list beside it, and closing it brings the full-width list back to the same message, instead of the top of the list either way.
- **Sends that only half worked say so.** A reply or forward that went out but left no copy in Sent, or could not mark the original, now says so, worded as the success it was so nobody sends it twice.

## Upgrade Guide

- Existing Windows installations can use **Update Paperclip** directly from the UI pill or tray.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
- The replied and forwarded marks, Sent copies and forward marking need the email-tools plugin 0.19.0 (paperclip-extensions v0.79.0) or later.
