# v2026.929.0

> Released: 2026-09-29
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **The home page says what actually needs you.** The Overview and the all-companies Brief only say "All systems green." when nothing is wrong. Otherwise the line says what is: agents in error (named, with a link to each), budget incidents, blocked tasks and items waiting on you, and the dot beside it changes colour to match. "Awaiting your tap" now links straight to Attention.
- **The Work list opens on work that is still open.** Finished tasks are hidden until you turn on "Show finished", the Assignee column is on by default, the list says how many routine runs it is hiding, and an open task that nobody is assigned to is marked. Any view you have saved still wins.
- **Attention is shorter.** The Mine view leaves out approvals you have already decided, and identical rows fold into one with a count.
- **Approval cards fit on the screen.** The raw request data no longer stretches each card off the right edge; it sits behind a details toggle. A message waiting for approval shows who it goes to and what it says, and "View details" sits next to the title.
- **A stopped agent says why, in plain words.** An expired sign-in says so and points to Adapters, the raw error is shown once behind Details, the button reads "Try again", and "See what went wrong" opens the failed run. An agent that is waiting on you shows "Needs you" on its page and on Team instead of "idle".

## Fixes

- **New issue from the all-companies view asks which company it is for.** It used to file the issue under HQ without asking.
- **Agents no longer fall back to an expired sign-in without a word.** When Switchboard has no account to offer, Paperclip keeps using the account Switchboard named most recently for up to a day (it was 30 minutes), and stops reusing an account once it fails to sign in. When a run does fall back to the computer's own sign-in, the server log says so with Switchboard's reason, the run records it, and a sign-in failure on that run explains what happened.

## Upgrade Guide

- Existing Windows installations can use **Update Paperclip** directly from the UI pill or tray.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
- The sign-in change takes effect once the Paperclip server restarts.
