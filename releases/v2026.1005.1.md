# v2026.1005.1

> Released: 2026-10-05
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Updating from Paperclip on a Mac.** After an update, rebuild or restart started from Paperclip, the server reopens in a new Terminal window with the same settings it had before, so Ctrl-C there stops it as usual. If the update fails, a macOS alert says which step failed, whether Paperclip is still running, and how to recover.

## Fixes

- **A refused update no longer looks like a dead button.** Update, Rebuild, Restart and Shut down now show the reason when they cannot go ahead: local changes in the checkout, the wrong branch, Rust missing, or a server that was not started by the launchers. On macOS and Linux these checks now run before anything stops, so the old server keeps running.
- **No more promise of a console window on macOS and Linux.** The confirm boxes no longer say a console window will open. After you confirm, a message says where the progress is going on that machine.
- **A restart no longer writes the server's settings into a command line.** On macOS and Linux, a restart from Paperclip used to put the server's whole environment, tokens included, into a command line that other users of the same computer could read. It is now passed along privately.
- **Long file paths in messages wrap** instead of running out of the message box.
- **Google review replies through Review Tools still wait for your approval.** Replies posted through the renamed Review Tools plugin need your go-ahead, as the old Google Business plugin's did, and the "Reply to every Google review" starter works with either plugin.

## Upgrade Guide

- Windows: use **Update Paperclip** from the UI pill or tray as before.
- macOS and Linux: the update to this version still runs with the scripts already installed, so the server comes back in the background with its output in `~/.paperclip/logs/maintenance.log`. Updates after this one get the new behavior. On a Mac, to get the server back into a Terminal window now, run `stop-paperclip.command` and open the Paperclip app.
- The macOS behavior is covered by automated tests on macOS, but has not yet been tried by hand on a Mac.
- Server changes take effect once Paperclip restarts. The update restarts it for you.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
