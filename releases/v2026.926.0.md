# v2026.926.0

> Released: 2026-09-26
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **See what a file is without opening it.** On an issue, hovering over or tabbing to an attached file shows its name, type, size, who uploaded it and when, plus a preview: the first page of a PDF, or the first 40 lines of a text, markdown, CSV or JSON file. Clicking a file or image opens a full-screen viewer that steps through every attachment on the issue with the arrow keys, has a Download button, and closes with Escape, so a click never leaves the page. Each file row also shows a small file-type icon.
- **Agents can set reminders for the person who approved them.** A new agent permission, "Can set reminders for you" on the agent's page, lets an agent a person has approved create calendar reminders owned by that person.

## Fixes

- **Reinstalling an add-on no longer fails over line endings.** Paperclip fingerprints each add-on database update so an applied one cannot be changed afterwards. The fingerprint used to include the file's line endings, so the same file checked out with Windows line endings one day and Unix line endings another looked edited, and a reinstall stopped with "Plugin migration checksum mismatch". Line endings are now ignored, older fingerprints are still accepted, and a real change to the SQL is still refused.

## Upgrade Guide

- Existing Windows installations can use **Update Paperclip** directly from the UI pill or tray.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
- Word, Excel and zip attachments show their details but no preview; previewing those would need a converter on the server.
