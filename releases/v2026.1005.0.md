# v2026.1005.0

> Released: 2026-10-05
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Company memories.** Clippy can now remember, recall and forget things for a company, and everyone with access to that company shares them. Memories are encrypted at rest with the same key that protects company secrets. Each company can also mirror its memories to a folder of plain Markdown files (a synced Google Drive folder works well), on a schedule or by hand from the Memories page, and edits made in that folder come back in. Agents now get the company's memories in their prompts.
- **Email reads like Outlook.** An open email shows a To line and a Cc line under the sender, each person by name with the full address on hover, so a message you were copied on no longer looks as though it went to someone else. Forwarded and printed emails include the Cc line too. A new Reading pane button above the message list offers Right, Bottom and Off: Bottom puts the full-width list above the message with a line you can drag, and Off opens a message in place of the list with a Back button.
- **Links in emails open in your browser.** Clicking a link in an email opens it in a new browser tab instead of inside the message, where most sites only showed a "JavaScript must be enabled" notice.
- **macOS and Linux installers.** Paperclip now installs, updates, rebuilds and restarts on macOS and Linux with managed launchers, plus a Finder shortcut on macOS.
- **Features brought over from upstream Paperclip.** Pipelines and Cases, new Cursor Cloud, Grok, Kimi and Hermes adapters, multi-user access with attribution, the skill studio, and a translation catalog for 40 languages. Pipelines, Cases, Approvals, Automations, Intake Queues, Goals, Projects and the portfolio pages now open with a short explanation of what they are for.
- **Clippy can help with IT support.** Clippy can run diagnostics, repairs and replies for a company when it has that company's support permission, and asks for your go-ahead in the chat before it acts.

## Fixes

- **New Clippy chats start on your chosen model.** Clippy ignored the default model set on the Agent Defaults page and always started on the Claude app's own default. It now starts on the model chosen there for the adapter it uses, and the "Used by default" tag in its model list matches.
- **Help Scout emails can no longer run code inside Paperclip.** They are now shown in a frame that blocks scripts, as other emails already were.
- **Issues Clippy creates get proper numbers.** They used to be created without an issue number. Existing ones are numbered by this update, and a chat now shows which company it is working in.
- **Windows updates no longer hang on "No pending migrations".** A leftover database process could hold the migration step open until it was ended by hand.
- **Unix updates are more reliable.** The backup now runs before the server stops (it used to fail and leave Paperclip stopped and not updated), and a lockfile rewritten by the installer no longer blocks updates.
- **Security hardening from upstream.** Invite codes are harder to guess and are rate limited, sign-in tokens are signed per company and per instance, and plugin records belong to a company.
- **Pipelines and Cases pages no longer bounce you to the Brief.** Both are now turned on by default.

## Upgrade Guide

- Existing Windows installations can use **Update Paperclip** directly from the UI pill or tray. macOS and Linux installations update with the new update launcher.
- The update applies database migrations, including the one that numbers issues Clippy created.
- Check the Claude default on the Agent Defaults page: new Clippy chats now start on it.
- Server changes take effect once Paperclip restarts. The update restarts it for you.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
