# v2026.1008.0

> Released: 2026-10-08
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Fixes

- **Email keeps the view you chose.** The All mail, Unread and With agents tabs could switch, and save the switch, without being clicked, so opening an unread email from Portfolio Email sometimes landed on All mail and loaded every message. The tabs now change only when you click one (or press Enter or Space on it).

## Upgrade Guide

- Use **Update Paperclip** as before. This is a screen-only change, so a page refresh picks it up.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
