# v2026.923.0

> Released: 2026-09-23
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **AI Draft in the email pop-out.** The reply box in the full-size email pop-out, which Portfolio Email opens (and so does "Open full size" on a company's Email page), now has the same AI helper as the company Email page: an instructions box, a model picker, and the AI Draft / AI Revise button.

## Fixes

- **One model choice everywhere.** The model picked for AI Draft is shared between the Email page and the pop-out, so a choice made in one is the model the other drafts with.
- **From line in the pop-out.** The pop-out's reply and forward boxes now show the address the message will be sent from, as every other composer does.
- **Attach files in the pop-out reply.** Files can now be attached to a reply sent from the pop-out.
- **No crossed drafts.** An AI draft that finishes after you have moved to a different email is dropped instead of landing in the new reply box.

## Upgrade Guide

- Existing Windows installations can use **Update Paperclip** directly from the UI pill or tray.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
