# v2026.1007.1

> Released: 2026-10-07
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Security

- **Agents can no longer change what another agent runs on your computer.** A CEO agent, or an agent allowed to hire, could set another agent's command, arguments or environment, or turn it into a plain process agent. Only a person signed in to Paperclip can change those now, on hiring, editing or rolling back an agent. Agents can still attach a saved secret to another agent's environment.
- **A task can no longer point at another company's project or goal.** Before, the other company's project name, status and goal could show on the task.

## Upgrade Guide

- Use **Update Paperclip** as before. Server changes take effect once Paperclip restarts, and the update restarts it for you.
- If one of your agents sets plain environment values or commands on other agents through the API, that now fails with a message asking for a board member. Set those from the Paperclip screens instead, or store the value as a secret and bind it.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
