# v2026.1028.1

> Released: 2026-10-28
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Human-Readable Approval Titles & Context** — Replaced cryptic, repeating tool identifiers (such as `email_mark_read: email-tools:email_mark_read`) with natural language action labels and parameter summaries (e.g. `Mark email read: mailbox m3-barry, UID 280179`).
- **Structured Tool Call Parameters** — Replaced the raw JSON database dump on the Approval Detail page and cards with a clean, structured parameters grid and action badges, filtering out internal database plumbing (`runId`, `chatSessionId`, `agentId`).
- **Linked Issue & Requester Visibility** — Attention Queue and Portfolio Brief ("Awaiting your tap") rows now display who requested the action and the associated issue identifier and title (e.g. `MME-454: Triage m3-barry mailbox`), so you know exactly what work each approval belongs to.

## Improvements

- Added humanized tool mappings for common email actions (`email_mark_read`, `email_mark_unread`, `email_move`, `email_save_contact`, `email_import_contacts`), Slack actions, Google Workspace events/tasks, and GitHub operations.
- Intercepted outbound tool drafts now pre-resolve and embed the associated issue details at draft creation time.
- Receipts and Portfolio Receipts feeds reflect concise, humanized action names for outbound drafts.

## Upgrade Guide

- Use **Update Paperclip** as before.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
- No database migration is required.
