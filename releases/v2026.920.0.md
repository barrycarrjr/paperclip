# v2026.920.0

> Released: 2026-09-20
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Start Paperclip with Windows** — The Windows tray menu now includes a checked **Start with Windows** toggle. It registers Paperclip for the current Windows user and starts the server and tray quietly at sign-in without opening a browser tab.
- **Team operations consoles** — Company and portfolio Team views now lead with current work, attention states, live controls, reporting-line groups, timelines, agents, org charts, and assistants. ([#10](https://github.com/barrycarrjr/paperclip/pull/10), @barrycarrjr)
- **Multi-company operations shell** — The control center has clearer Portfolio, HQ, and company scope; pinned workspaces; tracked email-to-agent handoffs; Start work planning; and broad company-scoping fixes. ([#8](https://github.com/barrycarrjr/paperclip/pull/8), @barrycarrjr)
- **Governed plugin operations** — Plugins can declare an operation once for both agents and screens, with structured failures, idempotency for writes, operator policy controls, and approval gates.

## Improvements

- **Safer Windows maintenance** — Update, rebuild, restart, and blank-screen repair paths now preserve the tray, wait for server health, recover from stuck process families, and report progress instead of leaving Paperclip silently offline.
- **Hierarchy-aware team visibility** — Team views derive reporting lines from existing agent relationships, handle incomplete or cyclic data safely, and expose branch filters and organization-level attention without adding a second hierarchy model.
- **More reliable plugin upgrades** — Bulk updates stay online and show progress, temporary download failures can retry, and dropped sockets no longer permanently block an upgrade.

## Fixes

- **Actionable mail errors** — Mail actions now explain why they failed instead of appearing to do nothing.
- **Self-healing Windows UI cache** — The launcher validates generated Vite dependencies, rotates damaged cache generations, and provides a one-click repair action for blank screens.
- **Quiet duplicate startup launches** — A Windows sign-in launch exits without opening a browser when an existing tray instance already owns the launcher mutex.

## Upgrade Guide

- Existing Windows installations can use **Update Paperclip** or **Rebuild from local** from the tray, then right-click the tray icon and enable **Start with Windows** if desired. The setting is opt-in and applies only to the current Windows user.
- Database migrations `0095`–`0099` apply automatically. They add tracked email delegations, pinned workspaces, Start work request containers, plugin operation calls, and plugin operation policies.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
