# v2026.922.0

> Released: 2026-09-22
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Restored full menu snapshot on rail hover** — When the sidebar is collapsed, hovering over or focusing a company icon on the rail now shows the full menu snapshot in peek mode, including "Where you left off", user-pinned workspaces (such as Portfolio Email, Portfolio Brief, etc. on HQ), "Control center", and "Everything".

## Fixes

- **Pinned workspace visibility in collapsed navigation** — Resolves an issue where hovering over HQ or company icons in the collapsed rail only displayed a minimal shortcut list, restoring immediate access to all pinned workspaces and tools.

## Upgrade Guide

- Existing Windows installations can use **Update Paperclip** or **Rebuild from local** from the tray.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
