# v2026.1028.2

> Released: 2026-10-28
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Explicit `assignee` Support in Chat Tools** — Declared the `assignee` parameter directly in the tool schemas for both `create_issue` and `update_issue`, allowing Clippy and board users to smoothly assign tasks to Builder (or other agents) using either `assignee` or `assigneeAgentId`.

## Upgrade Guide

- Use **Update Paperclip** as before.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
- No database migration is required.
