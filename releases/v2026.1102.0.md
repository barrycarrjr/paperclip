# v2026.1102.0

> Released: 2026-11-02
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Email snooze.** Hide an email until later and have it come back unread in the folder it came from. Snooze from the buttons above an open email, from the hover buttons on any email in the list, or for a whole sender group at once, on both the company Email page and the HQ all-mail page. Choices are Later today, Tomorrow, Later this week, This weekend and Next week, each showing its real time, plus "Pick date & time" with a calendar.
- **See what is snoozed.** A "Snoozed" tab on the company Email page and a "Snoozed" button on each mailbox in the HQ all-mail page list every snoozed email, when it comes back, and a "Bring back now" button. A snooze that keeps failing to come back is flagged with the reason.
- **Finished agent work no longer goes unseen (#184).** When an agent sets an issue it holds to `in_review` without naming a reviewer, the issue is handed back to the person who created it. Any `in_review` issue still held by an agent with no person assigned now appears in the attention queue as waiting for review.

## Upgrade Guide

- Use **Update Paperclip** as before.
- Snooze needs the email-tools plugin release that adds snooze support (`paperclip-plugin-email-tools` 0.24.0 or later). Update it from the Plugin Library.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
- No database migration is required.
