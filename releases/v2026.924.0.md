# v2026.924.0

> Released: 2026-09-24
>
> Fork-only GitHub release for `barrycarrjr/paperclip`. This release is not published to npm.

## Highlights

- **Model lists that keep up by themselves.** Every place you pick a model (agent settings, new agents, onboarding, issue overrides, Agent Defaults, Clippy and email drafts) now shows what each provider offers your account today, instead of a list written into Paperclip. Claude models come from the installed Claude Code itself, Codex models from the installed Codex, and API-key providers from their own model lists. New models appear without a Paperclip update, and retired ones drop off. Today that means Claude Opus 5.5, Claude Fable 5.1 and the GPT-6 models are all offered.
- **New, retiring and older models are marked.** Models released in the last 30 days are tagged New, a retiring model shows the date it stops working, and older models are folded under "Older models" so the current ones come first. The model each tool uses when none is chosen is tagged "Used by default".
- **A warning when an agent's model needs attention.** If an agent's model has been replaced, is retiring, or is no longer offered, its settings say so in one line with a Switch button. A daily check also adds an activity entry when a new model appears, and one per agent whose model needs updating. Paperclip never switches an agent's model by itself.

## Fixes

- **New Codex agents start on a model Codex still offers.** They used to be set to `gpt-5.3-codex`, which Codex no longer lists. They now get the model Codex itself uses by default.
- **Clippy, email drafts and quick AI helpers pick today's best model.** They no longer fall back to fixed older models such as Claude Opus 4.7 or GPT-4.1.
- **Images work with the newest models.** Claude 5 models, GPT-6 and current Gemini models are now recognised as able to read images.
- **Refresh really refreshes.** The refresh button in model pickers asks the provider again, for every kind of agent.

## Upgrade Guide

- Existing Windows installations can use **Update Paperclip** directly from the UI pill or tray.
- This is a GitHub-only release of the `barrycarrjr/paperclip` fork. No `paperclipai` npm dist-tag is changed.
- Paperclip now downloads a public model catalog (models.dev) once a day for release dates and retirement flags. Set `PAPERCLIP_MODEL_CATALOG_URL=off` to turn that off, and `PAPERCLIP_MODEL_CLI_DISCOVERY=off` to stop Paperclip asking the Claude and Codex programs for their model lists.
- A new model only shows up once the Claude Code or Codex program on the machine knows about it, so keep those programs updated.
