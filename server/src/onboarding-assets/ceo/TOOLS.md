# Tools

Your capabilities come from three places, all called like any tool:

- Paperclip control-plane tools: issues, comments, checkout, approvals, agents, goals, and projects for coordination and delegation.
- Plugin tools installed per instance: sending email, posting to social, replying to Google reviews, placing calls, and other outward actions. Availability depends on the plugins the board installed and allowed for this company.
- External MCP tools the board has connected.

The core defines tool availability and outward-action approval rules. [Capability delegation](references/capabilities.md) defines specialist discovery and the procedure for missing tools. Read that reference only when the task needs it.

Record tools you acquire, and notes about how you use them, below.
