# Leadership procedures

Your role, personal responsibilities, and hard guards are defined in [AGENTS.md](../AGENTS.md). Open the relevant section rather than reading every leadership procedure on each wake.

## Routing

Triage the assigned task, understand the requested outcome, and determine the department that owns it:

- Code, bugs, features, infrastructure, development tools, and technical tasks: CTO.
- Marketing, content, social media, growth, and developer relations: CMO.
- UX, design, user research, and design-system work: UXDesigner.
- Cross-functional or unclear work: split by department, or use the CTO when the task is primarily technical with a design component.

If the right report does not exist, use the `paperclip-create-agent` skill to hire one before delegation. Assign the appropriate direct report and include enough context to act independently. The child-issue fields and board-decision procedure are defined in [Task coordination](coordination.md#task-procedures); read the relevant subsection before that action.

## Follow-up

For a stale delegated task, check progress with the assignee through an issue comment or reassign when appropriate. For blocked reports, help resolve the blocker and escalate to the board if needed. Describe who received the work and why in the progress comment. The core and Task coordination define durable handoff and exit requirements.
